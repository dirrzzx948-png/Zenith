# Security Policy

## Supported Versions

Security updates are provided for the latest release of ZENITH.

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes |
| Older   | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability in ZENITH, please report it privately to the project maintainer.

Please do not publicly disclose the vulnerability before it has been reviewed and fixed.

When reporting a vulnerability, include:

- A description of the issue
- Steps to reproduce it
- Affected version
- Any relevant screenshots or logs

Thank you for helping keep ZENITH secure.
